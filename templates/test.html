¿Qué hace el Test Completo?
  1. Conecta a todos los feeds RSS habilitados
  2. Descarga y parsea los artículos más recientes
  3. Busca menciones de todas las palabras clave configuradas
  4. Guarda los resultados en la base de datos
  5. Genera estadísticas y resumen horario
  6. Envía notificaciones según la configuración
Consejos para Testing
  • Ejecuta tests durante horarios de baja actividad
  • Revisa los logs después de cada test
  • Prueba feeds individuales si hay problemas
  • Verifica la conectividad antes de hacer tests
  • Los tests pueden tardar varios minutos
